# LMS Backend

A production-oriented Learning Management System (LMS) backend built with NestJS, GraphQL, TypeORM, MySQL, Passport, and JWT.

The goal of this project is to design and implement a scalable LMS platform while following real-world backend engineering practices, including modular architecture, database migrations, authentication and authorization, GraphQL APIs, and clean domain-driven design.

## Tech Stack

* NestJS
* GraphQL (Code First)
* TypeORM
* MySQL
* Passport.js
* JWT Authentication
* TypeScript

## Project Goals

* Build a complete LMS backend from scratch
* Follow production-grade architecture and best practices
* Use TypeORM migrations instead of schema synchronization
* Implement role-based access control (RBAC)
* Design a maintainable and scalable GraphQL API
* Track progress through incremental feature development and daily commits

## Planned Features

### Authentication & Authorization

* User registration and login
* JWT-based authentication
* Role-based access control
* Protected GraphQL resolvers

### User Management

* Admin, Instructor, and Student roles
* User profile management

### Course Management

* Create and manage courses
* Course publishing workflow
* Instructor-owned courses

### Course Content

* Sections
* Lessons
* Content organization and ordering

### Enrollment System

* Student enrollments
* Course participation tracking

### Learning Progress

* Lesson completion tracking
* Course progress calculation

### Future Enhancements

* Quizzes and assessments
* Certificates
* Course reviews and ratings
* File and media uploads
* Notifications
* Payment integration

## Development Approach

This project is being developed incrementally with a focus on:

* Domain modeling before implementation
* Clean module boundaries
* Separation of concerns
* Production-ready database migrations
* Consistent commit history documenting project evolution
